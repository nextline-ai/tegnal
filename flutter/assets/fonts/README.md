# Pretendard

Bundled unmodified from the official Orion Cactus Pretendard v1.3.9 release:

- https://github.com/orioncactus/pretendard/tree/v1.3.9/packages/pretendard/dist/public/variable
- https://github.com/orioncactus/pretendard/tree/v1.3.9/packages/pretendard-jp/dist/public/variable

The primary Pretendard variable font covers Korean and Latin. Pretendard JP is
the bundled Japanese fallback. Both are distributed under the SIL Open Font
License 1.1; see OFL.txt. Typography works without network access.
