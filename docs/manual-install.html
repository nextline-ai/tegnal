최신 버전과 자동 업데이트를 원하시면 TestFlight를 이용하세요. IPA는 직접 설치와 업데이트를 관리할 수 있는 분을 위한 선택 항목입니다.

권장 설치 · TestFlight

Apple TestFlight에서 자동 업데이트를 켜면 새 빌드도 같은 경로로 받을 수 있습니다.

TestFlight에서 설치

수동 설치 전에 확인해 주세요

  • IPA 설치본은 TestFlight 자동 업데이트를 받지 못합니다. 새 버전을 직접 확인하고 설치해야 합니다.
  • 모든 버전이 IPA로 배포되지는 않습니다. 최신 버전은 TestFlight에 먼저 올라옵니다.
  • AltStore Classic·SideStore 등에서 다시 서명해야 하며, 서명 갱신과 iCloud 기능은 계정·설치 도구에 따라 달라집니다.
  • 기존 설치본에서 옮기기 전에는 앱의 백업 기능으로 보관함을 저장해 주세요.

IPA 파일은 별도의 수동 설치용 배포 경로에서 제공합니다.
