# TEGNAL Google Play 등록 문안

Android `1.0.0-beta.4+6`의 실제 기능을 기준으로 작성한 붙여넣기용 문안입니다. 앱 이름은 모든 언어에서 **TEGNAL**입니다. 이전 Apple 스토어 문안에서는 작품 탐색과 폴더 정리의 톤만 참고했습니다.

각 언어 폴더에는 필드 값만 있는 UTF-8 텍스트 파일이 있습니다. 파일명은 `title.txt`, `short-description.txt`, `full-description.txt`, `release-notes.txt`입니다. 등록정보와 출시 노트는 별도 Console 입력란에 넣으세요.

| 언어 | 제목 / 30 | 짧은 설명 / 80 | 자세한 설명 / 4,000 | 출시 노트 / 500 |
| --- | ---: | ---: | ---: | ---: |
| [한국어](ko-KR/full-description.txt) | 6 | 40 | 1,584 | 228 |
| [English](en-US/full-description.txt) | 6 | 72 | 2,955 | 443 |
| [日本語](ja-JP/full-description.txt) | 6 | 38 | 1,389 | 206 |

위 표는 마지막 파일 개행을 제외한 문자 수입니다. 마지막 개행을 포함한 수와 UTF-16 코드 단위 수도 한도 이내인지 확인했습니다. 필드별 결과는 [length-check.json](length-check.json)에 있습니다.

기재한 범위는 직접 연결한 호환 사이트, 두 라이브러리 모드, 폴더·태그·검색·뷰어·지원 다운로드, 지원 형식의 가져오기·JSON 백업, 가져오기 후 만화 정보 자동 채우기, 로컬 취향 통계와 외부 번역 앱 전달입니다. 사이트·외부 앱의 고유 브랜드는 문안에 넣지 않았습니다. 실제 구현과 지원 형식은 [심사 안내](../review-instructions.md)와 [beta4 검증 기록](../../../flutter/docs/android-beta4-validation.md)에서 별도로 확인할 수 있습니다.

자동 정보 채우기에는 연결한 호환 만화 사이트와 인터넷이 필요하며, 화면을 사용하는 동안 실행하고 일시정지할 수 있음을 알립니다. 가져오기 범위의 형식별 차이, 미디어·일부 원본 기록의 JSON 백업 제외, 번역의 외부 앱 의존성과 앱 내 클라우드 동기화 불가도 설명합니다. 내장 AI·자체 번역 엔진·완전 오프라인·활성 클라우드 동기화·정보 전송 없음 등의 주장은 하지 않습니다.

문안 작성 완료는 제출 승인이나 게시 확인을 의미하지 않습니다. [제출 체크리스트](../submission-checklist.md)의 콘텐츠 정책 대응, 대상 연령·등급, 개인정보처리방침 URL과 데이터 보안 답변을 실제 제출 구성과 최종 대조하세요. 다른 콘텐츠에 접근할 수 있는 범위를 이 문안만으로 제한하거나 승인받았다고 가정하지 않습니다.
