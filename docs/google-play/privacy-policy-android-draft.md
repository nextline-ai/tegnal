## 기기에 보관하는 정보

Android 앱은 작품·폴더·작가·태그·메모·사이트 주소·설정·검색 기록·읽던 위치·다운로드 정보를 기기의 앱 저장소에 보관합니다. 이미지와 만화 기록은 모드별로 구분합니다. 라이브러리 데이터베이스는 앱의 로컬 SQLite 저장소이며 앱 전체 데이터베이스를 별도 암호화한다고 약속하지 않습니다.

취향 분석은 기본으로 활성화되어 저장·해제·열람 활동과 작품 메타데이터를 별도의 로컬 기록으로 보관합니다. 기존 보관함을 처음 한 번 초기 자료로 사용할 수 있습니다. 생성형 AI 모델을 내려받지 않고 기기 안에서 통계를 계산합니다. 설정에서 새 분석을 중단하거나 분석 기록을 초기화할 수 있습니다. 초기화해도 저장 작품은 유지되며 기존 작품을 자동으로 다시 분석하지 않습니다. 추천을 가져올 때 사용하는 태그 등 검색 조건은 연결한 사이트에 전달됩니다.

## 연결한 웹사이트와 네트워크

작품 검색·메타데이터·이미지·영상 요청은 연결한 사이트 및 관련 미디어 서버로 전달됩니다. 해당 서비스는 IP 주소, 요청 URL과 검색어·작품 식별자, 사용자 에이전트, 필요한 인증 정보와 쿠키를 받을 수 있습니다. 사이트가 추가 리소스를 로드할 수 있으며, 각 운영자의 개인정보처리방침이 적용됩니다. TEGNAL 개발자는 외부 사이트의 기록 보관·재이용·삭제를 통제하지 않습니다.

백업 가져오기에 성공하면 빠진 커버·제목·태그를 채우기 위해 연결된 호환 사이트로 작품 식별자 조회와 커버 이미지 요청을 자동으로 보냅니다. 상단 안내에서 일시정지할 수 있으며, 사이트가 없으면 연결을 기다립니다. 앱이 백그라운드에 있는 동안 새 작업을 진행하지 않습니다.

내장 브라우저는 로그인·접속 확인에 사용되며 쿠키와 웹사이트 저장소를 기기에 유지합니다. 일부 지원 API 요청은 확인된 웹사이트 문맥에서 실행되고 결과가 앱으로 전달될 수 있습니다. 앱 소유의 웹 요청은 HTTPS를 요구하고 인증서 오류를 무시하지 않습니다. 이것이 외부 서비스의 모든 처리에 대한 종단간 암호화나 익명성을 의미하지는 않습니다.

Android 연결 실패를 복구하는 일부 경로에서는 Cloudflare의 `cloudflare-dns.com/dns-query`로 암호화된 DNS 질의를 보냅니다. 이때 대상 호스트명과 연결에 필요한 네트워크 정보가 DNS 제공자에게 전달됩니다. 시스템 DNS 제공자는 기기·네트워크 설정에 따라 달라집니다. ECH 지원 여부는 경로와 기기에 따라 다르며 VPN이나 모든 네트워크 정보의 은폐를 보장하지 않습니다.

## 인증 정보와 삭제 범위

사이트 계정명·API 키는 플랫폼 보안 저장소에 보관하고 해당 HTTPS 사이트 인증에 사용합니다. 지원 엔진에 따라 HTTP 인증 헤더 또는 URL 질의 항목에 포함되므로 수신 사이트는 이를 처리하고 기록할 수 있습니다. 앱의 JSON 라이브러리 백업에는 비밀 인증 정보와 브라우저 쿠키를 포함하지 않습니다.

사이트 계정 입력란을 비워 저장하면 해당 앱 저장 인증 정보를 제거할 수 있습니다. 쿠키 초기화는 해당 주소에서 보이는 쿠키와 해당 출처의 웹 저장소를 대상으로 하며 다른 경로의 로그인까지 모두 지워진다고 보장하지 않습니다. 사이트 연결 제거는 로컬 연결을 보관 처리하고 저장 작품을 유지합니다. 이 동작을 사이트 계정·모든 쿠키·외부 서비스 기록의 일괄 삭제로 설명하지 않습니다.

## 번역과 다른 앱으로 보내기

번역을 선택하면 설치된 Google 번역 앱의 지원 여부를 확인합니다. 지원되는 경우 현재 보이는 이미지를 임시 파일 URI와 읽기 권한으로 전달합니다. 이미지 공유를 지원하지 않는 경우에는 사용자가 별도로 이미지 저장을 선택해야 Pictures/TEGNAL에 저장하고 Google 번역을 엽니다. 갤러리 사본은 사용자가 직접 삭제할 때까지 남을 수 있습니다. 공유용 임시 파일은 앱 캐시에 저장되며 다음 공유 시 오래된 파일 정리를 수행합니다. 24시간이 지나면 항상 즉시 삭제된다고 약속하지 않습니다.

TEGNAL은 자체 문자 인식·번역 서버나 AI 모델 다운로드를 제공하지 않습니다. Google 번역은 자체 네트워크와 서비스를 사용할 수 있고 해당 서비스의 정책이 적용됩니다. 오프라인 번역이나 외부 앱의 보관 기간을 보장하지 않습니다. 공유·외부 브라우저·이메일·커뮤니티 링크를 선택하면 선택한 앱이나 서비스가 관련 정보와 통신을 처리합니다.

## 파일, 백업과 보관 기간

사용자가 선택한 파일로 백업을 가져오고 요청한 경우 JSON을 내보냅니다. 파일 선택기의 제공자가 클라우드 서비스일 수 있으며 앱 밖의 내보낸 파일은 직접 삭제해야 합니다. 다운로드와 이미지 캐시는 앱 로컬 저장소를 사용하고 캐시는 다시 생성될 수 있습니다. 캐시 삭제는 저장 작품이나 외부 서비스 기록 삭제와 별개입니다.

Google Drive 동기화는 이 Android 버전에서 일시적으로 비활성화되어 자동 Google 로그인이나 라이브러리 Drive 동기화를 실행하지 않습니다. Android에는 Apple iCloud/Vision 기반 동기화·번역이 적용되지 않습니다.

라이브러리는 Android의 시스템 백업·기기 이전 대상이 될 수 있습니다. 기기 설정과 운영체제/백업 제공자에 따라 처리되며, 앱 백업 규칙은 WebView 데이터·검증 경로 설정·Drive 비교 자료 일부를 제외합니다. 모든 데이터가 기기 밖으로 나가지 않는다거나 보안 저장소가 모든 시스템 백업에서 제외된다고 보장하지 않습니다. 공개 전 최종 기기/백업 동작을 확인합니다.

검색 기록 보관 기간과 기록 저장 여부를 설정하거나 기록을 삭제할 수 있습니다. 저장 작품·메모·폴더 등은 해당 삭제 동작 또는 앱 데이터 삭제 전까지 유지됩니다. 폴더 삭제는 작품 자체 삭제와 다릅니다. 취향 활동 기록은 검색 기록과 별도이며 분석 초기화로 지울 수 있습니다. 앱 삭제 후에도 내보낸 파일·갤러리 이미지·운영체제 백업·외부 서비스 사본은 남을 수 있습니다.
