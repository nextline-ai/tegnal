# Android Data safety draft — investigation, not Console answers

Reviewed 2026-10-28. **Owner approval and final-artifact verification required.** Organization account verification and app-name registration are complete; Data safety submission is not recorded. The product decision is to remove bundled default connections and use generic feature names in listing copy. That does not remove the app's actual third-party content/data flows.

Google's definition includes off-device transmission to third parties, not just a developer server. Local-only data is different; open-web WebView use and user-initiated transfers have specific exceptions that must be assessed per flow. Ephemeral handling is not a blanket exemption. Use the [official Data safety guidance](https://support.google.com/googleplay/android-developer/answer/10787469?hl=en) when completing Console. Do not paste “No collection / No sharing” from this draft.

| Content search, catalog/detail/media requests: `flutter/lib/data/booru_source.dart`, `manga_source.dart`, `source_http_client.dart` | Search terms, requested work IDs/URLs, IP address, user agent and optional authentication/cookies reach configured sites and their media servers. Recommendation requests also send selected tags. | Assess **In-app search history**, **Web browsing history**, **App interactions/Other actions**, **User IDs**, **Device or other IDs**, as applicable. HTTPS does not prevent the receiving site from logging a credential-bearing URL. Secrets are excluded from app JSON backups, not presumed excluded from all OS backups. |
| Browser/sign-in: Android `BrowserActivity.kt`, `BrowserSession.kt`, `VerifiedWebFetch.kt`; Dart `session_client.dart` | Websites load content/resources; WebView keeps cookies and site storage. A blanket “all WebView data exempt” answer is unsupported. First-party cookies remain possible; third-party cookies are disabled in the visible browser. |
| Connection fallback: `manga_fallback_client.dart`, `MangaHttpTransport.kt` | On eligible Android connection failure, DNS-over-HTTPS requests go to `https://cloudflare-dns.com/dns-query` for the destination host; Cloudflare receives DNS hostname/IP/transport metadata. Native DNS also uses platform/network configuration. | Assess recipient/retention and applicable identifiers/browsing categories. This is DNS routing, not a claim that Cloudflare receives page contents as an application proxy. ECH is not anonymity, a VPN, or a promise of universal protection. |
| Local library/history/taste: `library_store.dart`, `taste_controller.dart`, `insights.dart` | SQLite stores saved works, folders, notes, artists/tags, sources, search history, progress and timestamped save/open/remove evidence. Statistical analysis is local; no generative model is downloaded. | Local storage alone is not off-device collection. Recommendation tags still leave the device. Search retention and taste reset are separate controls. OS backup is a separate flow below. |
| Installed translation: `InstalledTranslation.kt`, `installed_translation.dart`, reader action | Package capability check is local and targets only Google Translate. Explicit action shares the current rendered image via a read-granted content URI, or explicitly saves it to Pictures/TEGNAL and opens that app. | Evaluate Photos and videos/Photos and the user-initiated sharing exception. TEGNAL does not implement OCR/translation. Google Translate can use its own network/services; retention and offline availability are not verified. No installed-app inventory upload was found. |
| Imports/exports/downloads/share | User-chosen files, exported JSON with library information, downloaded source media and user-chosen link/image recipients. | Consider Files and docs, user-generated content, Photos and videos, and user-initiated exceptions per destination. Android bookmark import reads the selected SQLite file locally and retains original bookmark/read/crop records in the library database. Those original records are excluded from app JSON export, but the library remains subject to the OS backup/transfer flow below. Download-item paths and headers are not imported. After successful import, automatic metadata enrichment sends work-ID lookup requests and cover-image requests to the user-configured compatible source. The queue can be paused, waits when no source is configured and only runs in the foreground. Other imported data stays local until another action/backup transmits it. Gallery/exported copies persist outside the app. Do not assume every document provider is local. |
| Android backup/transfer: `backup_rules.xml`, `data_extraction_rules.xml` | Library remains eligible for OS-managed backup/transfer. WebView data, verified route preferences and Drive baseline directory are explicitly excluded. | Verify final Android/provider behavior and secure-storage exclusions. Do not claim all data stays on one device or claim credentials are guaranteed excluded. OS backup handling must be explained accurately even where Data safety exceptions apply. |
| Drive | `AppFeatures.googleDriveSyncEnabled=false`; main does not construct the sync controller. Google sign-in dependency remains bundled. | No enabled runtime auto-sign-in/Drive library sync in this release. Verify final artifact/SDK behavior; dependency presence alone does not prove collection. Future re-enablement requires revised disclosure. |
| Support, external links | User-chosen email, Discord, privacy/project links; external services receive communications/access metadata. | Support email may contain email address/message/attachments. Confirm developer retention and deletion handling. External services have their own policies. No dedicated advertising/analytics/crash-upload SDK appears in reviewed direct dependencies; confirm transitive/runtime inventory. |

## Console questions that remain open

- [ ] Capture a permitted-content runtime network inventory from the exact signed AAB; inspect all transitive SDKs and the **merged release manifest**. The app manifest declares INTERNET and package visibility for translation; plugins may contribute more, such as wake-lock support. No broad photo-library, contacts, microphone or location access is requested in the app-owned manifest, but that is not a final merged-permission certification.
- [ ] For every applicable data type, decide collected/shared, required/optional, purposes, retention, ephemeral processing and deletion availability. Authentication and optional translation are different from essential source requests.
- [ ] Confirm the global encryption-in-transit answer from all flows, including external app/provider behavior; app-owned website requests require HTTPS but that is not an end-to-end or universal third-party guarantee.
- [ ] Verify cookie/credential deletion scope and OS backup behavior. Source removal **archives the connection and keeps saved works**, and does not itself prove all credentials or website data were erased.
- [ ] Confirm no TEGNAL account creation in the submitted build. Third-party website accounts are separate; do not describe a nonexistent TEGNAL account-deletion mechanism. Provide actual local/support deletion instructions.
- [ ] Approve and publicly host the Android privacy policy; align in-app link, listing identity, Data safety and actual production behavior.

These are investigation categories, not a preselected Console form. Keep reviewed answers with the final version, network evidence and owner sign-off.
