# TEGNAL Google Play 제출 문서

**작성 완료: 2026-10-29 · Android 1.0.0-beta.5 (7).** 기존 Apple 제출 자료의 문체를 참고하고 Android 구현과 맞춰 다시 작성했습니다. Console에는 아직 입력·업로드·제출하지 않았습니다.

1. **[Console 입력 가이드](console-input-guide-ko.md)** — 등록정보, 앱 콘텐츠, 액세스, 연령·등급, 번들 입력 순서.
2. **[한국어·영어·일본어 스토어 문안](store-listing/README.md)** — 제목, 80자 설명, 4,000자 본문, 출시 노트. 텍스트 파일 내용을 복사하세요.
3. **[데이터 보안 입력표](console-data-safety.md)** — 코드/manifest 근거와 항목별 입력 후보, 확정이 필요한 부분.
4. **[심사 안내](review-instructions.md)** — 비밀번호 없는 사용자 지정 예시와 짧은 붙여넣기 문안.
5. **[Android 개인정보처리방침](../privacy-policy-android.md)** — 한국어·영어 공개 본문. 기존 앱의 방침 링크에서도 Android 문서를 찾을 수 있습니다.
6. **[AAB·서명·그래픽 점검](artifact-and-assets.md)** — 파일 해시, 기존 APK 업데이트 호환 및 이미지 규격.
7. **[제출 체크리스트](submission-checklist.md)** — 문서 작업으로 완료한 항목과 실제 제출 전 남은 항목.

스토어 소개에는 외부 사이트나 다른 뷰어의 브랜드를 넣지 않았습니다. 심사 안내에는 사용자가 지정한 접속 예시를 명시하고, 실제 기능·외부 콘텐츠 범위를 숨기지 않았습니다. 앱 자체에 기본 사이트를 다시 추가하지 않았고 이번 작업은 문서만 변경했습니다.
