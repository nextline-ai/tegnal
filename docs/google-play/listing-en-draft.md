## App name

TEGNAL

## Short description

Read images and comics from connected websites and organize your library.

## Full description

TEGNAL helps you read and organize images and multi-page works from connected websites.

• Browse and save images and comics in separate modes.
• Organize saved works in colored folders and browse artists and tags.
• Read with horizontal or vertical paging, continuous scrolling, zoom and resume.
• Keep notes and download permitted works for offline reading.
• Import supported existing libraries and backups, and export your library as JSON.
• View local taste statistics and recommendations based on saved and opened works. Pause or reset analysis in Settings.

Translation hands an image to the Google Translate app installed on your phone. If that app cannot receive shared images, you can explicitly save an image and import it from Google Translate. Availability depends on the installed app, its supported features and network access.

Browsing and fetching website content require an internet connection. Features depend on each site's availability, account requirements and API restrictions. Save, share and download only content you have rights to use, according to the site's terms.

Google Drive sync is temporarily disabled. JSON import and export remain available. TEGNAL is not the official app of connected websites or external translation services.
