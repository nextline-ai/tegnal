## 3. 타깃 연령과 콘텐츠 등급

**타깃 연령은 ‘만 18세 이상’만 선택하는 방향을 권장**합니다. 어린이를 대상으로 설계한 앱이 아니며, 사용자 지정 외부 콘텐츠와 심사 예시 서비스의 성인 이용 조건을 고려한 제안입니다. 이 선택은 사업자의 대상 고객 결정이며 IARC의 결과 등급과 다릅니다.

IARC 설문은 다음 사실을 기준으로 작성합니다.

- 게임이 아닌 앱입니다. 적합한 일반 앱 범주를 사용합니다.
- 인터넷에서 사용자가 선택한 외부 콘텐츠를 가져옵니다. **번들 이미지가 없다는 이유로 모든 콘텐츠 항목을 ‘없음’으로 답하지 않습니다.**
- 웹사이트 사용자 게시물과 임의 사이트 연결이 가능하며, 내장 브라우저로 웹 콘텐츠를 볼 수 있습니다. 웹 접근·사용자 생성 콘텐츠 질문이 나오면 이 사실을 반영합니다.
- TEGNAL 자체 채팅, 공개 게시물 업로드, 랜덤 유료 아이템, 현금 도박, 실시간 위치 공유 기능은 없습니다. 외부 웹페이지에 있는 기능과 앱 자체 기능을 해당 문항의 정의에 맞게 구분합니다.
- 성적 내용·노출·폭력·욕설의 빈도와 수준은 **전체 접근 가능한 제품 범위**를 기준으로 결정해야 합니다. 예시 사이트나 선택한 필터만 보고 ‘없음’을 선택하지 않습니다. 현재 제품을 특정 일반 콘텐츠만 제공하는 앱으로 보증할 근거는 없습니다.
- 결과 등급을 직접 ‘전체 이용가’ 등으로 정하지 않습니다. 실제 응답으로 산정된 등급을 검토합니다. 성인 타깃/높은 등급은 금지 콘텐츠 정책의 면제가 아닙니다.

이 콘텐츠 범위 판단은 문구 작업으로 대체할 수 없는 남은 제품 확인 사항입니다. Apple 심사나 TestFlight 승인도 Play 승인을 보장하지 않습니다.

## 4. 번들 업로드와 서명

업로드 파일: `flutter/build/releases/TEGNAL-1.0.0-beta.5.aab`

내부 출시명: `1.0.0-beta.5 (7)`

릴리스 노트: 언어별 [store-listing](store-listing/)의 `release-notes.txt`.

APK 파일은 GitHub 직접 배포용입니다. 새 Play 앱에는 준비된 **AAB**를 사용합니다. 먼저 내부 테스트 트랙에 올려 처리 결과와 사전 출시 보고서를 확인합니다. 승인된 조직 계정에는 신규 개인 계정 대상의 12명·14일 조건을 적용하지 않지만, 앱 검증이 생략되는 것은 아닙니다.

**Play App Signing을 확정하기 전에 [서명 안내](artifact-and-assets.md)를 읽으세요.** 기존 GitHub APK 사용자에게 삭제 없이 업데이트를 제공하려면 Play 배포 앱의 서명 인증서가 기존 APK와 호환되어야 합니다. 업로드 키와 앱 서명 키는 다릅니다. 비밀키를 저장소나 이 문서 묶음에 넣지 않습니다.

## 5. 그래픽과 마지막 확인

[자산 점검표](artifact-and-assets.md)에 실제 파일 규격과 사용 가능 여부를 정리했습니다. 현재 Apple 홍보 이미지의 iPhone·iCloud·Apple Intelligence 표현을 Android 스크린샷으로 제출하지 않습니다. 이번 요청 범위는 문서/입력문안이므로 새 스토어 그래픽 제작이나 원본 이미지 변경은 수행하지 않았습니다.

입력 문안·개인정보 본문은 준비되었지만 **그래픽, 전체 콘텐츠 범위 판단, 데이터 보안의 외부 처리 확인, Play 서명 선택 및 Console 검증**은 제출 전 남아 있습니다. 확인하지 않은 항목은 완료로 체크하지 않습니다.
