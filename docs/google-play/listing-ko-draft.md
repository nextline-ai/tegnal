# 한국어 스토어 설명 초안

상태: 제출 불가. [제출 체크리스트의 남은 콘텐츠 정책 검토](submission-checklist.md)을 먼저 해결해야 합니다. 아래 문구는 현재 구현된 도구 기능의 초안이며, 심사용으로 실제 기본 사이트나 접근 가능한 콘텐츠를 숨기는 용도로 사용하지 않습니다. 제품 범위가 바뀌면 설명도 다시 검토하세요.

## 앱 이름

TEGNAL

## 간단한 설명

웹사이트의 이미지와 만화를 읽고, 나만의 폴더로 정리하세요.

## 자세한 설명

TEGNAL은 연결한 웹사이트의 이미지와 여러 페이지 작품을 읽고 정리하는 앱입니다.

• 이미지와 만화 모드를 나누어 탐색하고 보관하세요.
• 저장한 작품을 색상 폴더로 정리하고, 작가와 태그를 찾아보세요.
• 가로·세로 페이지 넘김과 연속 읽기, 확대, 읽던 위치 이어보기를 이용하세요.
• 작품에 메모를 남기고, 허용된 콘텐츠를 내려받아 오프라인으로 읽으세요.
• 지원되는 기존 라이브러리와 백업을 가져오고, 라이브러리를 JSON 파일로 내보내세요.
• 기기 안에서 저장·열람 활동을 바탕으로 취향 통계와 추천을 확인하세요. 분석은 설정에서 중단하거나 초기화할 수 있습니다.

번역은 휴대폰에 설치된 Google 번역 앱으로 이미지를 전달하는 방식입니다. 해당 앱이 이미지 전달을 지원하지 않으면, 사용자가 직접 이미지 저장을 선택한 뒤 Google 번역에서 가져올 수 있습니다. Google 번역의 설치 여부와 기능, 네트워크 연결에 따라 이용이 제한될 수 있습니다.

웹사이트 탐색과 콘텐츠 요청에는 인터넷 연결이 필요합니다. 사이트별 제공 방식, 계정 및 API 제한에 따라 일부 기능을 이용할 수 없을 수 있습니다. 저장·공유·다운로드는 권리가 있는 콘텐츠와 해당 사이트의 이용 조건에 따라 사용하세요.

현재 Google Drive 동기화는 일시적으로 비활성화되어 있습니다. JSON 가져오기와 내보내기는 사용할 수 있습니다. TEGNAL은 연결한 웹사이트나 외부 번역 서비스의 공식 앱이 아닙니다.

## 제출 전 검토

제안 카테고리: 도서/참고자료 또는 도구 중 실제 승인된 제품 목적에 맞는 항목을 소유자가 선택. 타깃 연령, IARC, 지원 연락처와 개인정보 URL은 별도 확정이 필요합니다. 광고 없음·완전 오프라인·무수집·AI 번역·Drive 지원과 같은 미검증 표현을 추가하지 마세요. 문자 제한 출처: [Google Play 스토어 등록정보](https://support.google.com/googleplay/android-developer/answer/9859152?hl=en).
